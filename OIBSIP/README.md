### 🎯 Objective

Build a machine learning classification model capable of identifying the species of an iris flower based on its physical measurements.

### 📂 Dataset

The project uses the **Iris dataset provided by Scikit-learn**.

The dataset contains three flower species:

- Setosa
- Versicolor
- Virginica

### 🔹 Features

- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

### 🛠️ Work Performed

- Loaded the Iris dataset
- Converted the dataset into a Pandas DataFrame
- Checked dataset shape and data types
- Checked for missing values
- Generated descriptive statistics
- Performed Exploratory Data Analysis
- Created pairplot and scatter visualizations
- Created box plots
- Analyzed feature relationships
- Studied feature discrimination between classes
- Split the dataset into training and testing sets
- Trained multiple classification models
- Evaluated model performance
- Compared classification results
- Selected the best-performing model

### 🤖 Machine Learning Models

- Logistic Regression
- K-Nearest Neighbours
- Decision Tree
- Random Forest

### 📈 Evaluation Metrics

- Accuracy
- Precision
- Recall
- F1-Score
- Confusion Matrix

### 💡 Outcome

The project demonstrates how supervised classification algorithms can identify iris flower species using physical measurements and how model performance can be compared using multiple evaluation metrics.

# 4️⃣ Email Spam Detection with Machine Learning

### 🎯 Objective

Develop a Natural Language Processing and machine learning classification system that distinguishes between spam and legitimate messages.

### 📂 Dataset

The project uses an SMS/Email spam classification dataset containing two categories:

- Spam
- Ham

### 🛠️ Work Performed

- Loaded the text dataset
- Checked class distribution
- Analyzed spam and ham percentages
- Converted text to lowercase
- Removed punctuation
- Removed unnecessary characters
- Performed text preprocessing
- Removed stopwords
- Applied optional stemming/lemmatization
- Converted text into numerical features using TF-IDF
- Split the dataset into training and testing sets
- Trained multiple classification models
- Compared classification performance
- Created confusion matrices
- Analyzed precision, recall, and F1-score

### 🤖 Machine Learning Models

- Multinomial Naive Bayes
- Logistic Regression
- Support Vector Machine

### 📈 Evaluation Metrics

- Accuracy
- Precision
- Recall
- F1-Score
- Confusion Matrix

### 🧠 NLP Technique

**TF-IDF (Term Frequency–Inverse Document Frequency)** was used to convert text messages into numerical feature vectors that could be processed by machine learning algorithms.

### 🔍 Important Analysis

Recall is particularly important in spam detection because incorrectly classifying a spam message as legitimate may allow unwanted or potentially harmful content to reach the user.

### 💡 Outcome

The project demonstrates a complete NLP classification workflow, from text preprocessing and feature extraction to machine learning model training and evaluation.

# ▶️ How to Run the Projects

## 1. Clone the Repository

```bash
git clone https://github.com/your-username/OIBSIP.git
```

Replace `your-username` with your actual GitHub username.

## 2. Open the Project

```bash
cd OIBSIP
```

## 3. Create a Virtual Environment

### Windows

```bash
python -m venv .venv
```

Activate the environment:

```bash
.venv\Scripts\activate
```

### macOS / Linux

```bash
python3 -m venv .venv
```

Activate the environment:

```bash
source .venv/bin/activate
```

## 4. Install Required Libraries

If a root-level `requirements.txt` is available:

```bash
pip install -r requirements.txt
```

Alternatively, install the main dependencies:

```bash
pip install numpy pandas matplotlib seaborn scikit-learn nltk jupyter
```

## 5. Start Jupyter Notebook

```bash
jupyter notebook
```

Or open the repository directly in **Visual Studio Code** and open the required `.ipynb` notebook.

## 6. Run the Notebook

Open the required task folder and execute the notebook cells from top to bottom.

Each project folder contains its own documentation and supporting files where applicable.
